## 🌟 Overview

**ZenCraft Studio** bridges ancient Eastern spiritual heritage (Buddhist prayer malas, Taoist five-element crystals, and rare woods) with modern interactive 3D web technology. 

Users can curate authentic natural gemstones (Obsidian, Cinnabar, Hetian Jade, Tiger Eye) and rare sacred woods (Agarwood, Indian Sandalwood, Bodhi Seeds) on an intuitive circular canvas, preview realistic physical textures, receive real-time Five Elements (*Wu Xing*) balance diagnostics, and order bespoke artisan-crafted bracelets.

---

## ✨ Key Features

- **🎨 Interactive Circular Mala Canvas**: Full drag-and-drop gesture support, drag-to-reorder, and swipe-away bead removal.
- **💎 40+ Authentic Gemstones & Sacred Woods**: High-resolution photorealistic 4x macro textures for Bodhi seeds, Agarwood, Amber, Turquoise, Lapis Lazuli, and Gold foil beads.
- **☯️ Five Elements (Wu Xing) Energy Analysis**: Real-time algorithmic breakdown of Metal (金), Wood (木), Water (水), Fire (火), and Earth (土) equilibrium.
- **📏 Wrist Size & Bead Count Calculation**: Instant sizing guide based on wrist circumference (14cm to 20cm) and bead diameter (6mm to 15mm).
- **🔒 100% In-Browser Privacy**: Your custom designs and spiritual profile selections execute entirely client-side.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16 (Turbopack)](https://nextjs.org/)
- **Frontend**: React 19, TypeScript
- **Canvas Rendering**: HTML5 2D/3D Context with High-DPI Super-sampling
- **Styling**: Tailwind CSS v4, Lucide Icons
- **Deployment**: [Vercel Global Edge Network](https://vercel.com/)

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/mywgit/ZenCraft.git
cd ZenCraft

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to enter the 3D bracelet studio.
